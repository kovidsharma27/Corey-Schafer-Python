## What I Learned

- Learned what functions are and why they are used.
- Learned how to define a function using `def`.
- Learned how functions help reuse code instead of writing the same code repeatedly.
- Learned how `pass` can be used when a function does not have any statements yet.
- Learned how to call a function using its name followed by `()`.
- Learned the difference between referring to a function and calling a function.
- Learned how to return a value from a function using `return`.
- Learned that a function without a return value returns `None`.
- Learned about built-in functions such as `len()`.
- Learned how to perform operations on a value returned by a function.
- Learned about function parameters and arguments.
- Learned how to pass arguments to parameters.
- Learned how to use default parameter values.
- Learned how to change a default parameter value by passing an argument.
- Learned how to pass arguments by position and by keyword.
- Learned about `*args` for positional arguments.
- Learned about `**kwargs` for keyword arguments.
- Learned that `*args` stores positional arguments in a tuple.
- Learned that `**kwargs` stores keyword arguments in a dictionary.
- Learned how `*` can unpack values from a list or tuple into function arguments.
- Learned how `**` can unpack key-value pairs from a dictionary into keyword arguments.
- Learned the difference between `key=value` in function arguments and `key:value` in dictionaries.
- Learned how one function can be used inside another function.
- Practiced creating functions such as `is_leap()` and `days_in_month()`.
- Learned how to use a function's return value in another function.
- Learned about docstrings inside functions.
