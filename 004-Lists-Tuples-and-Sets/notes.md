## What I Learned

- Learned how to create and use lists in Python.
- Learned that lists can contain homogeneous as well as non-homogeneous values.
- Learned how to find the length of a list using `len()`.
- Learned how to access individual list elements using indexing.
- Learned how negative indexing works in lists.
- Learned how to slice a list using `[start:end]`.
- Learned how to add elements to a list using `append()`.
- Learned how to insert an element at a specific position using `insert()`.
- Learned how to add one list to another using `insert()`.
- Learned the difference between `append()` and `extend()`.
- Learned how to remove a specific value using `remove()`.
- Learned how to remove and retrieve the last element using `pop()`.
- Learned how to reverse a list using `reverse()`.
- Learned how to sort a list using `sort()`.
- Learned how `sort(reverse=True)` sorts values in descending order.
- Learned how `sorted()` creates a new sorted list without modifying the original list.
- Learned how to find the minimum, maximum, and sum of numerical values using `min()`, `max()`, and `sum()`.
- Learned how to find the index of a value using `index()`.
- Learned how to check whether a value exists in a list using `in`.
- Learned how to loop through the elements of a list using a `for` loop.
- Learned how to use `enumerate()` to get both the index and value while looping.
- Learned how to change the starting index of `enumerate()` using `start=`.
- Learned how to join list elements into a string using `join()`.
- Learned how to split a string into a list using `split()`.
- Learned that assigning one list to another variable makes both variables refer to the same list.
- Learned about tuples and that they are immutable.
- Learned that tuple elements cannot be modified after creation.
- Learned about sets and that duplicate values are not stored.
- Learned that sets do not have fixed positions like lists and tuples.
- Learned how to check whether a value exists in a set using `in`.
- Learned how to perform set intersection using `intersection()`.
- Learned how to combine sets using `union()`.
- Learned how to find elements present in one set but not another using `difference()`.
