## 📝 Notes Format

Each `notes.md` follows a consistent structure:

- **Status** — completion state of the video
- **What I Learned** — key concepts covered
- **What I Practiced** — hands-on functions/methods used
- **Main Concepts** — short explanations with code snippets
- **Important Commands / Examples** — quick reference of syntax
- **Practical Example** — a small runnable demo
- **Verification** — cross-platform notes, edge cases, gotchas
- **Key Takeaway** — one-line summary of the topic
