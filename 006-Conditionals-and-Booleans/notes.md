## What I Learned

- Learned how `if` statements work in Python.
- Learned that the statements inside an `if` block execute when its condition is `True`.
- Learned how to use relational operators in conditions.
- Learned how to use `if` and `else` together.
- Learned how `else` executes when the `if` condition is `False`.
- Learned how to use `elif` for checking additional conditions.
- Learned how multiple `elif` conditions are checked.
- Learned how to use Boolean values in conditions.
- Learned how the `and` operator works and that both conditions must be `True`.
- Learned how the `or` operator works and that at least one condition must be `True`.
- Learned how the `not` operator reverses a Boolean value.
- Learned the difference between `==` and `is`.
- Learned that `==` checks whether two values are equal.
- Learned that `is` checks whether two variables refer to the same object.
- Learned how `id()` can be used to see the identity of an object.
- Learned that two separate lists can have equal values but different identities.
- Learned that assigning one list to another variable makes both variables refer to the same object.
- Learned about truthy and falsy values in Python.
- Learned that `False`, `None`, `0`, empty lists, empty dictionaries, empty strings, and empty tuples evaluate to `False` in conditions.
- Learned that other non-empty or non-zero values can evaluate to `True` in conditions.
