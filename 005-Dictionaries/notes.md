## What I Learned

- Learned that dictionaries store data in `key:value` pairs.
- Learned how to create a dictionary.
- Learned how to access a value using its key.
- Learned that keys can be different types of values.
- Learned how to use `.get()` to access a dictionary value.
- Learned that `.get()` returns `None` when a key does not exist.
- Learned how to provide a default value using `.get(key, default)`.
- Learned how to add a new key-value pair using `dictionary[key] = value`.
- Learned how to update an existing value using `dictionary[key] = new_value`.
- Learned how to update multiple values using `.update()`.
- Learned how `.update()` can both update existing keys and add new keys.
- Learned how to delete a key-value pair using `del`.
- Learned how to remove a key-value pair using `.pop()`.
- Learned how to store the value removed by `.pop()` in a variable.
- Learned how to find the number of keys in a dictionary using `len()`.
- Learned how to access all keys using `.keys()`.
- Learned how to access all values using `.values()`.
- Learned how to access all key-value pairs using `.items()`.
- Learned how to loop through dictionary keys.
- Learned how to loop through both keys and values using `.items()`.
